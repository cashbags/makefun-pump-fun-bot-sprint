A Solana trading bot for pump.fun-style bonding curves. It scouts every
curve, buys only coins already climbing toward the 85 SOL graduation
line on real inflow, pyramids into strength, and exits fast on any sign
the flow turned. Deterministic: no clock, no randomness, no network.

See [DESIGN.md](DESIGN.md) for the measured edge, fee math, and guards.
